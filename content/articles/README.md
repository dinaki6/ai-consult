# Статьи

Сюда добавляются MDX-файлы статей. Файлы `README.md` и другие `.md` не публикуются —
читатель берёт только `.mdx`.

Пример frontmatter:

```yaml
---
title: "Название статьи"
excerpt: "Короткое описание или первые два предложения."
date: "2026-11-07"
topics:
  - "automation"
readingTime: "6 мин"
---
```

Доступные темы: `automation`, `strategy`, `analytics`, `support`.
