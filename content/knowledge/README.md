# База знаний

Сюда добавляются MDX-файлы руководств и чек-листов. Публикуются только `.mdx`.

Пример frontmatter:

```yaml
---
title: "Название руководства"
excerpt: "Короткое описание материала."
date: "2026-11-07"
category: "Чек-лист"
level: "Начальный"
readingTime: "8 мин"
topics:
  - "strategy"
---
```

Категория и уровень показываются в списке и на странице материала.
